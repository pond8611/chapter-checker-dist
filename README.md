# Chapter Checker distribution

รีโพนี้ใช้เฉพาะแจกอัปเดตและเก็บรายการสิทธิ์ของ Chapter Checker เท่านั้น

- ผู้ใช้โปรแกรมอ่าน `access.json` แบบสาธารณะโดยไม่มี token
- เครื่องที่ไม่อยู่ในรายการถูกปฏิเสธตามค่าเริ่มต้น
- เฉพาะบัญชี GitHub `pond8611` หมายเลข `165383609` เท่านั้นที่ workflow ยอมทำงาน
- การอนุญาต/บล็อก/ลบ ทำจากหน้า Actions > Owner access control > Run workflow
- รายการเก็บเพียง hash เฉพาะโปรแกรม ไม่เก็บ MachineGuid ดิบ รหัสผ่าน หรือ IP
- label เป็นข้อมูลสาธารณะ จึงห้ามใส่ชื่อจริง อีเมล เบอร์โทร หรือข้อมูลส่วนตัว

ไฟล์ release ของโปรแกรมจะถูกอัปโหลดเป็น GitHub Release แยกจาก branch `main` นี้
