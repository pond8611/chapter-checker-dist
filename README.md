# Chapter Checker distribution

รีโพนี้ใช้แจกอัปเดตและเก็บสำเนาถาวรของรายการบล็อก Chapter Checker เท่านั้น

- รุ่น 4.1.0+ อ่าน `control/blocklist.signed.json` แบบสาธารณะโดยไม่มี token และยอมรับเฉพาะลายเซ็น RSA ของกุญแจ access เจ้าของ
- ค่าเริ่มต้นคืออนุญาต เครื่องจะถูกปิดสิทธิ์เมื่อ device hash อยู่ในรายการบล็อกที่มี revision ใหม่กว่าเท่านั้น
- เจ้าของเปลี่ยนรายการจากแผง native ในโปรแกรม; แผงตรวจ GitHub numeric user id `165383609` ก่อนเขียนไฟล์นี้
- ไฟล์ public เก็บเฉพาะ device hash, label สั้น และข้อความบล็อก ห้ามใส่ชื่อจริง อีเมล เบอร์โทร IP หรือข้อมูลส่วนตัว
- `access.json` และ workflow เดิมคงไว้เฉพาะรองรับ launcher v3 ระหว่างย้ายรุ่น; v4.1.0 ไม่ใช้เป็นระบบสิทธิ์

ไฟล์ release ของโปรแกรมจะถูกอัปโหลดเป็น GitHub Release แยกจาก branch `main` นี้
